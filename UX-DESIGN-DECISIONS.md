# UX principles applied to this portfolio

Reference: `UX-Principles-and-Laws.pptx` provided by the user.

- **Hick's Law:** one primary hero action, with resume as the secondary action; four curated projects rather than a long unfiltered catalog.
- **Fitts's Law:** larger tap targets for theme and mobile navigation; project selection uses large clickable rows.
- **Jakob's Law / consistency:** conventional top navigation, clear sections, standard external links and contact actions.
- **Recognition over recall:** visible section labels, skill tags, selected-project state, and resume/contact links.
- **Progressive disclosure:** project details appear when a project is selected; initial page stays scannable.
- **Visibility of system status:** active project selection and dark/light toggle labels; theme preference is saved locally.
- **Accessibility:** skip-to-content link, focus-visible outlines, semantic sections, accessible navigation labels, reduced-motion support.
- **Error prevention:** no fake live demo or fabricated detection accuracy; computer vision illustration explicitly labelled conceptual.
- **60/30/10:** neutral base, secondary surfaces, restrained accent color in both themes.
- **Peak-End Rule:** memorable opening statement, closing contact call-to-action.

These are design heuristics, not a substitute for formal accessibility or usability testing.
