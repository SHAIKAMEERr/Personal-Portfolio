# Ameer Shaik — Developer Portfolio

A responsive personal portfolio built with React, Vite, JavaScript and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

The project can be deployed to Netlify or Vercel. Build command: `npm run build`; publish directory: `dist`.

## Portfolio sections

- Introduction and contact links
- Professional experience and engineering responsibilities
- System design, LLD, database design, security, performance and deployment
- Interactive project showcase
- Technical skills, education and certification
