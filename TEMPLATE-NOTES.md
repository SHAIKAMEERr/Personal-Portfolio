# Bold Systems — Ameer Shaik Portfolio

This is a complete standalone React + Vite portfolio template. It includes the same verified profile content, project case studies, resume PDF, responsive navigation, and an in-site dark/light theme toggle.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Theme

The theme toggle is in the top navigation. The template opens in **dark mode** by default.
